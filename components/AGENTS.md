# components

**Parent context:** `../AGENTS.md`
**Updated:** 2026-10-27

## Purpose
The ported NadavAI pages (`site/`).

## Key Files
| File | Description |
|------|-------------|
| `site/generated/page-*.tsx` | One server component per prototype page, generated by `scripts/port/sync.py`. Strings are `c(id)` / `r(id, tags)` deck lookups |
| `site/generated/chrome-*.tsx` | The shared header (with the language switch), footer and dock |
| `site/generated/pages.json` | Per page: stylesheets, body class and data, page module, meta ids, OG image |
| `site/page-shell.tsx` | Renders one page: its stylesheets, body attributes, markup and engine |
| `site/engine.tsx` | Client: loads GSAP, ScrollTrigger and Lenis from the CDNs, then the page module, after hydration |

## For AI Agents

### Working In This Directory
- Never edit `site/generated/`; change `scripts/port/convert.py` and re-run the sync.
- The markup is static server output that the vanilla modules in `public/site` drive. Do not add React state to it: a re-render would undo what a module changed.

### Testing Requirements
Visual changes need a side-by-side check against the prototype in `/he` and `/en`, at desktop and 390px.
