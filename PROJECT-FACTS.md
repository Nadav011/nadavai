## 7. Design and UI rules

These are project decisions, not generic advice:

- **Tailwind 4 CSS-first**: the theme lives in `@theme inline` inside `app/globals.css`; there is
  deliberately **no `tailwind.config.ts`**. Verified: no such file exists.
- **OKLCH P3 wide-gamut palette**: colors are `var(--color-cyan)`, `var(--color-pink)`,
  `var(--color-bg-deep)` and friends. New colors must be OKLCH — no new HSL or hex, because they
  fall outside the token system.
- **Animation split**: CSS scroll-driven animation (`animation-timeline: scroll()/view()`) for
  simple reveals, GSAP ScrollTrigger for complex sequences.
- **Lenis smooth scroll is synced to the GSAP ticker** — three critical lines in
  `components/gsap-setup.tsx`. Do not "simplify" them.
- **next-view-transitions** handles locale switching.
- **Sound**: Howler via `lib/sound.ts`, muted by default, respects `prefers-reduced-motion`.
- `prefers-reduced-motion` is required on **every** animation — the site animates continuously and
  has no global off switch.
- Every `linear-gradient(to right)` needs an RTL variant or a `/* rtl-ok */` comment, so review can
  tell a deliberate LTR gradient from a bug. (Project-specific convention.)
- Directional icons (Chevron/Arrow Left/Right) need `rtl:rotate-180`.
- Minimum 44px touch targets; `aria-label` on every interactive element.
- Custom utilities defined in `globals.css` — reuse instead of re-implementing: `glass`,
  `glass-strong`, `dot-grid`, `dot-grid-subtle`, `mesh-gradient`, `text-gradient`,
  `text-gradient-cyan`, `text-gradient-mixed`, `text-gradient-animated`, `glow-cyan`, `glow-pink`,
  `glow-text`, `gradient-border`, `grid-bg`, `section-divider`, `shader-fallback`, `holographic`,
  `noise-bg`, `scrollbar-hide`.
- Everything under `components/` is a client component (`"use client"`); server work and metadata
  stay in `app/`. The old CLAUDE.md said "34 files in components/" — the count is now 37 including
  `components/ui/`, so do not carry a hard-coded number into the new CLAUDE.md.
