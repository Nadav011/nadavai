# messages

**Parent context:** `../AGENTS.md`
**Updated:** 2026-10-27

## Purpose
All site strings, generated by `scripts/port/sync.py` from the copy deck. Never edit these files by hand.

## Key Files
| File | Description |
|------|-------------|
| `he.json`, `en.json` | Every deck string, keyed by deck id with `/` for `.`. Hebrew values carry the prototype's inline markup as `<t0>` tags |
| `js-ids.json` | The ids the ported modules read through `window.__t` |
| `error.json` | The error boundary's strings, which render outside the locale layout |

## For AI Agents

### Working In This Directory
- A new or changed string goes into a deck file (`COPY-FULL.md`, or `scripts/port/COPY-PORT.md` as a draft), then the sync.
